## 1. Role Profile Catalog

MASTERY curates standardized industry career profiles mapped to verified Bloom's taxonomy depth levels and practical competency standards. Rather than scraping volatile job boards or claiming real-time employer demand, MASTERY relies on curated, versioned, faculty-reviewed benchmarks.

### 1.1 Software Development Engineer - Backend (SDE)
- **Role Family:** Software Development
- **Experience Tier:** Entry-Level / Fresher
- **Version:** 1.0 (Faculty Reviewed)
- **Description:** Focuses on server-side architecture, scalable RESTful APIs, high-performance database design, concurrency, and automated testing.

#### Core Benchmarked Competencies:
1. **Object-Oriented & Functional Programming (Depth: Level 4/5, Importance: HIGH)**
   - Demonstrated mastery of design patterns, abstraction, and memory safety.
2. **Data Structures & Algorithm Optimization (Depth: Level 4/5, Importance: HIGH)**
   - Time/space complexity analysis, tree/graph traversal, and dynamic programming.
3. **Relational & NoSQL Database Design (Depth: Level 4/5, Importance: HIGH)**
   - Schema normalization, index optimization, ACID compliance, and query planning.
4. **RESTful API & Service Architecture (Depth: Level 4/5, Importance: HIGH)**
   - HTTP status semantics, payload validation, middleware, and authentication.
5. **Automated Testing & Test-Driven Development (Depth: Level 3/5, Importance: HIGH)**
   - Unit testing, mock dependencies, and integration test pipelines.
6. **Containerization with Docker (Depth: Level 3/5, Importance: MEDIUM)**
   - Multi-stage image building, container networking, and microservice orchestration.

### 1.3 Data Engineer
- **Role Family:** Data & AI
- **Experience Tier:** Entry-Level / Fresher
- **Version:** 1.0 (Faculty Reviewed)
- **Description:** Builds and maintains reliable data ingestion pipelines, analytical data warehouses, and batch/streaming ETL jobs.

#### Core Benchmarked Competencies:
1. **Advanced SQL & Analytical Queries (Depth: Level 4/5, Importance: HIGH)**
   - Window functions, recursive CTEs, partitioning, and execution plan optimization.
2. **Data Pipeline Architecture & ETL (Depth: Level 4/5, Importance: HIGH)**
   - Incremental loading, idempotency, data lineage, and failure recovery.
3. **Data Modeling & Warehousing (Depth: Level 4/5, Importance: HIGH)**
   - Star schemas, snowflake schemas, dimensional modeling, and OLAP vs OLTP.
4. **Distributed Processing Fundamentals (Depth: Level 3/5, Importance: MEDIUM)**
   - MapReduce concepts, Spark resilient distributed datasets, and columnar storage.
